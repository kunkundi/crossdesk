# CrossDesk 界面本地化

桌面端和 Android、iOS、HarmonyOS 移动端支持以下 10 种界面语言：

| 语言 | 标识 |
| --- | --- |
| 简体中文 | `zh-Hans` |
| English | `en` |
| Русский | `ru` |
| 繁體中文 | `zh-Hant` |
| 日本語 | `ja` |
| 한국어 | `ko` |
| Deutsch | `de` |
| Français | `fr` |
| Español | `es` |
| Português (Brasil) | `pt-BR` |

## 语言选择

- 新安装的桌面端默认“跟随系统”，也可以在设置中手动指定语言。已有配置中的中文、英文、俄文选择继续保留。
- 移动端使用系统语言；Android 和 iOS 同时支持操作系统提供的应用语言设置。
- 地区变体匹配相应语言；中文优先识别 `Hans` / `Hant`，台湾、香港、澳门使用繁体。葡萄牙语地区变体共用巴西葡萄牙语文案。
- 支持系统首选语言列表的平台使用其中可用的语言，没有匹配项时回退到英文。修改系统语言后重新打开应用可确保所有页面与状态文案更新。
- 只翻译应用界面。远端设备名称、文件名、用户输入、服务器公告和协议内容不作翻译。隐私政策正文使用项目已发布的中文或英文版本，第三方许可证保留原文。

## 语言显示不正确时

先检查系统首选语言或应用语言设置，重新打开 CrossDesk。桌面端也可以在设置中手动选择语言并保存。未翻译的设备名称、文件内容和公告保持原文，是正常行为。

如果发现界面翻译错误或文字被截断，可通过 [问题反馈](https://github.com/kunkundi/crossdesk/issues) 提供使用语言、客户端版本、所在页面及建议译文。截图中请遮住连接密码和私人内容。
