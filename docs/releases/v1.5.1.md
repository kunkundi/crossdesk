# **更新内容**

1. 新增Windows、macOS与Linux X11隐私屏，支持遮蔽被控端本地画面、屏蔽本地键鼠输入，并在断开连接或异常时自动恢复；远程会话保持正常操作。
2. 增强桌面端与iOS端P2P穿透能力，优化UDP打洞、ICE连接建立与带宽恢复，支持使用服务器下发的连接配置，并改善加密传输与旧版客户端的兼容性。
3. 新增Windows屏幕采集方式设置，支持DXGI、WGC与GDI；修复锁屏、隐私屏及未连接物理鼠标时远程光标不可见、位置异常和拖动窗口时出现重复光标的问题。
4. 优化画面缩小时的显示清晰度、帧率与分辨率恢复，修复Windows、macOS与Linux系统音频采集可能卡住的问题，提升远程画面与音频的稳定性。
5. 修复Linux X11远程键盘输入与macOS窗口缩放光标识别，改进鼠标操作和光标状态传输的可靠性；优化控制栏提示、网络状态布局与加密状态显示，并修复部分平台的Dock及任务栏图标显示问题。
6. 完善iOS/iPadOS连接失败提示，保留密码错误、设备不可用和网络中断等具体原因，简化服务器配置并优化原生客户端构建流程。

PC客户端版本为v1.5.1，iOS/iPadOS客户端暂未上架App Store，目前仅支持作为控制端连接远端电脑。隐私屏需控制端与被控端均支持，暂不支持Web及旧版客户端；macOS要求14.0及以上版本，Linux仅支持X11会话。
