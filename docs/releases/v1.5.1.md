# **更新内容**

1. 新增隐私屏，远程操作时可隐藏被控电脑的本地画面。
2. 隐私模式支持屏蔽本地键鼠，断开连接后自动恢复。
3. 提升远程直连成功率，改善网络波动时的连接稳定性。
4. Windows新增屏幕采集方式选择，方便适配不同设备。
5. 修复Windows锁屏、隐私模式或未连接鼠标时的光标显示异常。
6. 修复Windows拖动窗口时出现重复光标的问题。
7. 提升远程画面缩小时的清晰度，改善画面流畅度。
8. 修复开启或关闭远程声音时可能卡住的问题。
9. 修复Linux X11远程键盘输入异常。
10. 修复macOS窗口缩放时的光标显示问题。
11. 改进远程鼠标操作和光标同步的可靠性。
12. 优化控制栏提示和网络状态显示，新增连接加密状态。
13. 修复部分平台的Dock和任务栏图标显示问题。

PC客户端版本为v1.5.1。隐私屏支持Windows、macOS 14及以上版本和Linux X11，需连接双方均支持，暂不支持Web及旧版客户端。
