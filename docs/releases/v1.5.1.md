# **更新内容**

1. 新增隐私屏，可隐藏被控电脑的本地画面并屏蔽键鼠，断开连接后自动恢复。
2. 提升远程直连成功率，改善网络波动时的连接稳定性。
3. Windows新增屏幕采集方式选择，方便适配不同设备。
4. 修复Windows锁屏、隐私模式等场景下光标消失、错位或重复的问题。
5. 提升远程画面缩小时的清晰度，改善画面流畅度。
6. 修复开启或关闭远程声音时可能卡住的问题。
7. 改进远程键鼠操作，修复Linux X11键盘输入异常和macOS窗口缩放光标显示问题。
8. 优化控制栏提示、网络状态和程序图标显示，新增连接加密状态。

PC客户端版本为v1.5.1。隐私屏支持Windows、macOS 14及以上版本和Linux X11，需连接双方均支持，暂不支持Web及旧版客户端。
