# 桌面界面与操作入口

[返回首页](../README.md) · [完整使用指南](USER_GUIDE.md)

桌面客户端主要有主窗口、远程会话窗口和桌面墙三个入口。本文帮助你找到对应操作。

## 主窗口

| 入口 | 可以做什么 |
| --- | --- |
| 左上角连接模式 | 在设备 ID 和 IP 直连之间切换 |
| 本桌面 | 查看、复制本机连接信息，修改密码 |
| 远程桌面 | 输入对方 ID 或 IP 地址并发起连接 |
| 近期连接 | 重连设备、编辑别名和分组、删除记录 |
| 桌面墙 | 集中查看多台电脑 |
| 右上角菜单 | 打开设置、关于、更新检查和反馈 |

“已连接服务器”表示本机已连上 ID 服务；还需要输入对方 ID、完成密码验证，才能看到远端画面。IP 直连不依赖这个状态。

## 远程会话窗口

连接成功后，在会话工具栏切换显示器、开关声音、发送组合键、传文件或调整画面。鼠标悬停在图标上可以查看提示；工具栏收起时先展开。

**画面设置中的分辨率**会调整受支持的远端显示器模式。**桌面墙设置中的分辨率上限**只影响传输画面的清晰度，不改变对方显示器设置。详细区别见 [会话画面设置](USER_GUIDE.md#session) 和 [桌面墙](deskhub.md)。

## 桌面墙

从主窗口左上角进入。添加设备后可以按分组查看、放大画面、接管控制或批量传文件。放大画面默认只读，点击“接管操控”才发送键鼠。

群控会把输入发送到所有已连接设备，包括其他分组和分页中的设备。关闭桌面墙会断开全部远程设备连接；最小化不会断开。操作前请确认范围，详见 [桌面墙指南](deskhub.md)。

## 关闭窗口、后台运行与退出

- 关闭主窗口会隐藏界面，已有远程连接继续运行。可从系统托盘或 macOS 菜单栏重新打开。
- Windows 和 Linux 的主窗口、会话窗口可以分别切换和最小化；Linux 的任务栏分组方式取决于桌面环境。
- macOS 使用一个 Dock 图标；所有窗口关闭后，仍可从菜单栏打开 CrossDesk。
- 要完全退出普通桌面客户端，使用系统托盘或菜单栏的“退出”。Windows 开启无人值守后，退出界面仍可由后台服务提供远控；停用方法见 [无人值守说明](USER_GUIDE.md#windows-service)。

## 找不到某个功能

先在 **菜单 → 关于** 检查版本，再确认对应平台是否支持。移动端、Web 和 CLI 的入口与桌面端不同；开发版新增功能也可能尚未包含在下载的安装包中。
