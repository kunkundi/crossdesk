# 鸿蒙手机和平板使用指南

[鸿蒙安装说明](README.md) · [返回首页](../../README.md)

鸿蒙手机和平板客户端用于控制电脑，需要 API 20+、arm64 设备。当前是开发版，需要使用 DevEco 构建并签名。它不能把手机或平板共享为被控桌面。

## 首次连接

1. 按 [安装说明](README.md#自行构建) 构建移动包，在 DevEco 中签名安装。
2. 阅读隐私说明并同意联网，等待连接服务器。
3. 输入电脑的 9 位 ID 和连接密码；需要重连时选择保存密码。
4. 使用自建服务器时，在设置中填写与电脑相同的服务器。

## 会话操作

| 功能 | 操作方式 |
| --- | --- |
| 鼠标 | 相对模式像触控板；绝对模式直接定位。支持单击、长按右键及拖动 |
| 缩放和滚动 | 双指捏合缩放，放大后双指平移，原始比例下双指上下滑动滚轮 |
| 虚拟鼠标 | 从悬浮菜单打开左键、滚轮和右键控件 |
| 键盘 | 打开悬浮电脑键盘；“更多”提供常用、按键、系统和自定义组合 |
| 多显示器 | 从悬浮菜单选择远端显示器 |
| 画面 | 调整画质、30 / 60 fps 和画面偏好；不支持时选项不可用 |
| 声音 | 从悬浮菜单开关远端声音 |
| 隐私屏 | 直接开关电脑本地遮罩，查看电脑确认的状态；开启时屏蔽本地键鼠 |
| 网络状态 | 查看收发速率、丢包、分辨率、帧率、延时、直连 / 中继及加密状态 |

支持外接键鼠。手机可开启 **设置 → 屏幕方向 → 连接建立后锁定横屏**，平板和多窗口不受此开关影响。

当前文字输入入口为应用内悬浮键盘。自定义快捷键最多 16 个，每个远端平台最多固定 8 项；Linux 系统快捷键需选择 GNOME 或 KDE Plasma。Windows 的 `Ctrl+Alt+Del` 需要电脑端服务支持。

## 文件与剪贴板

通过系统文件选择器发送文件，接收完成后通过导出入口保存。传输详情显示进度和错误；断开前先等待传输完成并导出需要保留的文件。

剪贴板需要主动发送，单次文本上限为 128 KiB；收到远端文本后可手动复制。退出会话会清除会话内的文本。

## 配对可信设备

在 **设置 → 本机配对信息** 查看指纹并复制配对信息，在电脑的 **管理可信设备 → 添加可信设备** 中导入、核对并添加。之后即可使用密码连接开启“仅允许可信设备控制”的电脑。

重启、清理缓存和更换服务器不改变配对身份。清除应用数据、重装或换设备后需要重新配对。

## 后台连接与隐私

切换应用时优先使用系统画中画，无法使用时尝试后台任务与通知。系统拒绝后台运行、进程被终止或网络中断时，连接可能结束。不要把系统允许安装等同于后台连接始终可用。

保存远程画面预览默认关闭。开启后，后续连接会保存一张本地预览用于近期连接；关闭保存或撤回联网授权会清除预览。设置中可查看隐私说明及撤回授权，撤回会结束连接。

## 常见限制

- H.264 / AV1 优先硬件解码，不支持时使用软件解码；高分辨率和高帧率的表现取决于设备。
- 系统保留快捷键、画中画及后台权限因设备和系统而异。
- 鸿蒙与 Android 的常用功能相近，但不能据此假定两端所有操作和权限行为完全一致。
- 真机多屏、声音、后台和长时间会话的兼容性仍需在目标设备确认。

遇到问题请提供系统版本、设备型号、两端客户端版本和复现步骤，连接问题可先查看 [常见问题](../../docs/FAQ.md)。
